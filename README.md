# Oncology Clinical SAS Project

End-to-end Oncology Clinical Trial Project demonstrating Clinical SAS Programming, CDISC SDTM, ADaM and TLF development using realistic clinical trial data.

## Project Overview

This project simulates the complete clinical programming workflow from raw clinical trial data through SDTM, ADaM and reporting datasets.

Workflow:

Raw Data → SDTM → ADaM → TLF → QC Validation

## SDTM Domains Completed

* DM (Demographics)
* EX (Exposure)
* AE (Adverse Events)
* DS (Disposition)
* VS (Vital Signs)
* LB (Laboratory)
* TU (Tumor Identification)
* TR (Tumor Results)
* RS (Response Assessment)

## Technologies Used

* SAS 9.4
* Base SAS
* PROC SQL
* DATA Step Programming
* CDISC SDTM
* Clinical Trial Data Standards
* Oncology Clinical Trials

## Repository Structure

* raw_data/ – Source clinical trial datasets
* programs/ – SAS programming code for SDTM domains
* sdtm/ – Final SDTM datasets
* adam/ – ADaM datasets (in progress)
* tlf/ – Tables, Listings and Figures (planned)
* documents/ – Specifications and supporting documents
* outputs/ – Validation and output files
